# CodingGita LMS Clone

A modern, responsive Learning Management System (LMS) clone designed for students to track their academic progress, attendance, assignments, and more. Built with **React**, **Vite**, and **Tailwind CSS**.

## 🚀 Features

- **Student Dashboard**: A centralized hub for university info, UID, subjects, and mentors.
- **Attendance Management**: Track overall attendance and detailed semester-wise records.
- **Assignments Tracker**: View pending and completed assignments with a dedicated management page.
- **Academic Calendar**: Stay updated with important dates and events.
- **Application Portal**: Apply for leaves directly through the system.
- **Feedback System**: Submit feedback for courses and weekly subject performance.
- **Real-time Chat Interface**: Connect with mentors and peers (Mock implementation).
- **Profile Management**: View and manage student personal information.
- **Responsive Design**: Fully optimized for mobile, tablet, and desktop views using Tailwind CSS.

## 🛠️ Tech Stack

- **Frontend**: [React.js](https://reactjs.org/) (Version 19)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Routing**: [React Router DOM](https://reactrouter.com/)

## 📦 Installation

To get the project up and running locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/PriyanshCG/lms_clone.git
   cd lms_clone/lms-clone/ecommerce-app
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open in browser**:
   Navigate to `http://localhost:5173` (or the port shown in your terminal).
